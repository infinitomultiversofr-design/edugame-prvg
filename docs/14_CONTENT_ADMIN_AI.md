# 14 — Conteúdo, Administração e IA

## Pipeline curricular
1. importar fonte;
2. normalizar componente/ano/habilidade;
3. revisão humana;
4. publicar framework/version;
5. associar conteúdo.

Arquivos curriculares da escola não devem ser convertidos automaticamente em “verdade publicada” sem revisão.

## Banco de questões
Fluxo:
draft → review → approved → published → archived.

Cada questão registra:
- autor;
- revisor;
- versão;
- currículo;
- modificações.

## IA para professor
Permitido:
- rascunhar questão;
- sugerir distratores;
- sugerir dica;
- sugerir explicação;
- sugerir recurso;
- criar variação;
- analisar distribuição de respostas.

Obrigatório:
- marcar como draft;
- revisão humana antes de publicação.

## IA para estudante
Fase futura e controlada.
Primeira versão usa feedback/template aprovado, não chat generativo aberto.

Se tutor generativo for adicionado:
- conteúdo limitado à atividade;
- filtros;
- logging apropriado;
- sem diagnóstico;
- sem conversa privada não monitorável;
- professor pode revisar quando política permitir.

## Painel administrativo de conteúdo
- currículo;
- questões;
- vídeos;
- jogos;
- Avatar items;
- Pets;
- fundos;
- eventos;
- textos do Pet;
- quick-chat.

## Assets
Cada asset:
- id;
- tipo;
- source/master;
- versão otimizada;
- licença/originalidade;
- dimensões;
- alt text;
- status.

## Pipeline visual
Master → revisão → WebP/AVIF → CDN/Storage → manifest.

## Originalidade
Referências culturais geek servem como gênero visual.
Não usar:
- nomes de franquias;
- silhuetas icônicas copiadas;
- logos;
- símbolos protegidos;
- roupas que repliquem personagem conhecido.

## Administração de ano
- criar ano;
- copiar configurações opcionais;
- importar turmas;
- matricular;
- preservar estudante;
- encerrar período;
- snapshot;
- bloquear edição histórica indevida.
