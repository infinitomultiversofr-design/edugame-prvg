# Reference UI

Estas imagens são **targets visuais**, não especificações de dados.

Codex deve:
- reproduzir atmosfera, hierarquia, brilho, proporções e sensação premium;
- construir UI real, responsiva e acessível;
- não usar a imagem como background interativo;
- não copiar textos/números inconsistentes gerados na imagem;
- usar o Design System como autoridade de tokens e estados.

Subpastas:
- quiz: fluxo pedagógico do João;
- arena: jogos competitivos educacionais;
- avatar: editor e seleção;
- pet: linguagem visual do Pet;
- system: login e shells.
